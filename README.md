# Dis bonjour, renardeau ! 🇸🇰 🇫🇷

*(titre provisoire)*

Apprendre le français en s'amusant, pour les enfants slovaques de 8 à 12 ans.

Un cours de français pour enfants slovaquophones, construit sur le framework [Slovingo](https://github.com/lstux/Slovingo). C'est la version « enfants » du cours adulte [Slovingo-fr-sk](https://github.com/lstux/Slovingo-fr-sk), et la cousine du cours de slovaque pour enfants [Slovingo-sk-fr-kids](https://github.com/lstux/Slovingo-sk-fr-kids).

## Le monde

Tout se passe dans les Alpes françaises, près de Lyon. Toi, tu es une petite **líška** (renarde ou renard : le texte ne le précise pas) qui vient d'arriver dans la montagne. Tu apprends le français avec tes nouveaux voisins.

## Les personnages

| Avatar | Personnage |
