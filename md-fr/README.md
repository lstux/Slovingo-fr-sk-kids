# md-fr : traduction française de relecture

Ces fichiers sont une **traduction de relecture** des fiches de `md/`. Ils ne sont **pas lus par le build** (le moteur ne lit que `md/`) et ne servent qu'à juger ce que donne le cours quand on ne lit pas le slovaque.

## Comment lire

- Les **explications et notes slovaques** sont traduites en français.
- Dans les **cartes**, la ligne `>` donne le slovaque du cours, puis `⟶ « … »` sa **rétro-traduction littérale**. Quand le slovaque dit la même chose que le français, ça se voit tout de suite ; quand il s'en écarte (par exemple *prosím ťa* = « je te prie »), l'écart est noté.
- Dans les **tableaux**, la troisième colonne donne le sens littéral du slovaque.
- Les **décompositions mot à mot** (lignes `> Bonjour = dobrý deň`) ne sont pas reproduites : elles répètent les tableaux.
- Ce qui est lu par la voix slovaque dans le cours (`{{sk:…}}`) est écrit en texte normal ; les mots français sont en *italique*.
- Les phrases françaises (la matière du cours) sont reprises telles quelles.

Ces traductions sont à mettre à jour à la main si les fiches de `md/` changent. Une fois le slovaque relu par un locuteur natif, ce dossier peut être supprimé.
