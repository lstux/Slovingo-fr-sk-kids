# Relecture des séries 01 à 03 (Rodina, Doma, Jedlo)

Trois passes, comme pour le pilote : l'enfant slovaque de 8-10 ans, le pédagogue, le bilingue. Les séries ont été vérifiées par scripts (mots inconnus dans les cartes, ordre des mots complémentaires, décomptes de mots nouveaux, nombre de cartes audio, aucun `[[fr:`, aucune lettre isolée en `{{…}}`) puis relues fiche par fiche.

Légende : 🔴 faux ou bloquant, 🟠 à améliorer, 🟢 détail, ✅ corrigé.

**Limite** : aucune de ces passes n'a été faite par un locuteur natif. Le slovaque reste à faire relire.

## Questions ouvertes pour un locuteur natif

- *Mamie Odile* est une chamois (🦌 par défaut). Alternative à l'idée « animal des Alpes » ?
- Âges : Léa 9 ans, Hugo 8 ans, Andrea 11 ans. Léa est la grande sœur de Hugo.
- *Izba* pour *la chambre* ; *poď dnu* pour *entre !* ; *olovrant* pour *goûter* ; *milý / veselý* pour *gentil / joyeux* ; *robím palacinky* vs *pečiem palacinky*.
- *Astérix* (Doma 03) : connu des enfants slovaques ? La blague *il lit / le lit* tient-elle ? La blague *ma puce / mon chou* ?

## Bilan

- Peu de fautes de slovaque trouvées, mais l'auteur est aussi le relecteur : un regard extérieur reste nécessaire.
- Les pièges de genre (maison/dom, livre/kniha, clé/kľúč…) sont traités dans les fiches elles-mêmes.
