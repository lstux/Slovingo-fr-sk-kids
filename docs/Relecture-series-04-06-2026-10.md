# Relecture des séries 04 à 06 (Dedina, Zvieratá, Hry)

Trois passes, comme pour les séries 01 à 03 : l'enfant slovaque de 8-10 ans, le pédagogue, le bilingue. Contrôles par scripts (mots inconnus dans les cartes, cartes audio = lignes `!`, aucun `[[fr:`, aucun `{{sk::`, aucune lettre isolée en `{{…}}`), puis relecture de toutes les cartes avec leur slovaque.

Légende : 🔴 faux ou bloquant, 🟠 à améliorer, 🟢 détail, ✅ corrigé.

**Limite** : aucune de ces passes n'a été faite par un locuteur natif, et l'auteur est aussi le relecteur. Le slovaque reste à faire relire.

## Passe 1 — « Je suis un enfant slovaque de 9 ans »

| | Où | Remarque | Suite |
|---|---|---|---|
| 🔴 | Zvieratá 03 (Encore) | « Ovca **je** trávu » : *je* (jedáva) se dit des personnes ; une brebis *žerie* ou *pasie sa*. | « Ovca žerie trávu ». ✅ |
| 🔴 | Zvieratá 05 | « Mám **rád** zvieratá » : masculin, alors que le renard est neutre. | « Zvieratá sa mi páčia ». ✅ |
| 🟠 | Hry 01 | Intro « Hráš sa **rád**… » : même problème. | « Baví ťa hra… ». ✅ |
| 🟠 | Zvieratá 02 | Note « Mačka-kocúr : oba sa povedia chat » : bizarre. | « Mačku aj kocúra voláš chat ». ✅ |
| 🟠 | Zvieratá 02 | « Päť písmen, ale len tri hlásky » pour *oiseau* : faux (6 lettres, 4 sons). | Corrigé. ✅ |
| 🟢 | Zvieratá 05 | Intro « Hugo má pre Léu malé prekvapenie » : il n'y a pas de surprise. | « Hugo si doberá Léu ». ✅ |

| | Où | Remarque | Suite |

## Questions ouvertes pour un locuteur natif

- *Dedina* (vs *obec*), *poštár*, *ježko*, *na ulici*, *chodíš do školy*, *kruhový objazd*.
- *Spí ako svišť* : existe-t-il en slovaque ?
- *Ovca* pour *le mouton* ; *kozorožec alpský*, *orol skalný* ; *žerie trávu*.
- *Hrať sa* / *hrať* ; *švihadlo* ; *zahráme sa* pour *on joue* ; *máš pravdu*.
- *Zajac* pour *le lièvre* alors qu'Andrea est *zajačica* : même animal ?

## Bilan

- Fautes de slovaque trouvées : trois (*je trávu*, *rád* ×2), toutes corrigées. Fautes de français : une note de prononciation (*grosse*).
- Les pièges de genre (*mouton/ovca*, *chat/mačka*, *place/námestie*, *village/dedina*) sont traités dans les fiches.
- Les trois séries ont chacune un dialogue avec ≤ 3 mots signalés et 1 forme à écouter.
