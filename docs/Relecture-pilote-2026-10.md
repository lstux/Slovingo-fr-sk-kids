# Relecture du pilote — octobre 2026

Document de travail, **à supprimer** une fois le slovaque relu par un locuteur natif.

Relecture du pilote (Introduction 01-05, Kit 01-04) en trois passes successives :

1. **Enfant slovaque de 8-10 ans** : on note ce qui bloque, sans corriger.
2. **Prof** : on traite l'ordre pédagogique et le respect du format.
3. **Traducteur bilingue sk/fr** : on corrige les traductions et le slovaque.

Légende : 🔴 faux · 🟠 maladroit ou à améliorer · 🟢 détail · ✅ corrigé

## Passe 2 — Le prof : pédagogie et respect du format

| | Point | Correction |
|---|---|---|
| 🔴 | Mots inconnus non signalés (règle du format) : *à demain*, *Madame*, *Monsieur*, *et toi*, *un peu*, *tout*, *d'eau*, *veux*, *voulez*, *du pain*, *tiens*, *voilà*, *je sais pas* | Chaque mot vu dans une carte est maintenant dans un tableau (nouveaux mots, mots complémentaires ou vocabulaire du dialogue). ✅ |
| 🔴 | Mot utilisé avant d'être appris (*merci* dans Kit 01, *voilà* avant Intro 02, *à demain*) | Ordre revu ; *voilà* et *c'est* sont introduits en Intro 02 ; *merci* arrive en Kit 02. ✅ |
| 🔴 | Dialogue Kit 03 : 6 phrases ou mots nouveaux pour 3 permis | 3 nouveautés signalées par `+ Nová fráza` : *je m'appelle*, *tu parles français ?*, *je ne comprends pas*. ✅ |
| 🟠 | Passé (*je ne savais pas*) hors du niveau de l'Introduction | Remplacé par le présent (*je ne sais pas*), puis retiré. ✅ |
| 🟠 | Inversion *Parles-tu* avec l'explication *est-ce que* | Retirée : on garde *Tu parles français ?*. ✅ |
| 🟠 | Intro 03 : l'article est expliqué de façon fausse (« muž, žena, zviera ») | Réécrit : *le/la* = « ten/tá », *un/une* = « jeden/jedna », et surtout le genre peut changer d'une langue à l'autre (*slnko* neutre, *le soleil* masculin). ✅ |
| 🟠 | Intro 04 : trop de théorie pour un enfant, exemples trop savants (*rare* = *vzácny*) | Trois sons seulement (*u/ou*, nasale, *r*), mots simples (*rue*, *rouge*). ✅ |
| 🟠 | Intro 05 : 11 mots d'un coup | Exception acceptée pour les nombres de 0 à 10, comme en sk-fr-kids. |
| 🟠 | Kit 01 : la règle *bonjour* = adultes, *salut* = copains est trop simple. En France, les enfants disent aussi *bonjour* | Règle corrigée : *bonjour* se dit à tout le monde, *salut* seulement aux copains et à la famille. ✅ |
| 🟠 | Kit 02 : le *tu/vous* était illustré avec des phrases de grammaire hors niveau | Illustré avec *s'il te/vous plaît* et *pardon* (« prepáč » / « prepáčte »). ✅ |
| 🟠 | Kit 02 : le piège slovaque *prosím* (deux sens) n'était pas traité | Section « Prosím má dve tváre » : *s'il te plaît* ≠ *de rien*. ✅ |
| 🟠 | Fiches sans « Doplnkové slová », sans « On révise », sans dialogue structuré | Ajoutés selon le format (sections `Doplnkové slová`, `On révise`, `Slovná zásoba dialógu`, `Postavy`). ✅ |
| 🟠 | Extra du Kit : pas de scènes, mots nouveaux | 4 scènes de 4 répliques, 16 cartes au total, aucun mot nouveau. Le gag « Madame Andrea » reprend le *vous*. ✅ |
| 🟠 | Intro 04, 05 : lettres isolées en `{{…}}` (la voix lit le nom de la lettre : « enne », « erre ») | Lettres sorties des `{{…}}` ; `{{ou}}` conservé (la voix française le lit bien). ✅ |
| 🟢 | Noms de fichiers du Kit en slovaque | Passés en français (`salutations`, `politesse`, `dialogue`, `extra`) comme dans Slovingo-fr-sk. ✅ |

## Questions ouvertes pour un locuteur natif

- *líštička* : forme et sens affectif du diminutif à confirmer.
- *zajka* : usage réel entre enfants, comme petit nom d'une hase.
- *Ahoj* pour *salut* : trop familier ? À écouter.
- *kozorožec* : mot connu des enfants de 8 ans ? Sinon, une alternative à tester (*horská koza*).
- L'enfant tutoie-t-il *Madame* en jouant (scène 3 de l'extra) : la blague passe-t-elle en slovaque ?
